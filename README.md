# StegChat Backend

This repository contains the **backend** for the StegChat project – a modular monolith providing:

- FastAPI HTTP API (versioned under `/api/v1`).
- Core contracts for carriers, crypto, detector, etc.
- A simple SQLite development database (configurable via `DATABASE_URL`).
- Placeholder modules that will be implemented by the student team.

The codebase is deliberately minimal to let multiple contributors develop independent modules in parallel.
